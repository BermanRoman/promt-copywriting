# Копирайтинг с проверкой результата

Корень библиотеки находится на три уровня выше этого файла.

Прочитай [мастер-промпт](../../../prompt-copywriter.md), определи режим и выбери профиль в [процессе](../../../workflow.md).

Подключай только нужные карточки, голос и роли по таблицам этих документов.

Аудит не меняет исходный текст, а короткая правка не запускает полный выпуск.

Для полного письменного текста нужен отдельный Васька-читатель, для сценария Motion — отдельный Гусар после фактчека и затем Васька-зритель.

Передавай Ваське только его роль, актуальный текст и предусмотренные решения повторного круга.

Сохраняй версию и результаты проверок по `workflow.md`; при работе с файлами используй [инструмент состояния](../../../docs/loop-tool.md), когда он уменьшает ручную работу.

Готовность относится к проверенной версии, лимит повторов и отсутствие обязательного исполнителя не скрываются.

Проектные согласования и уже данная авторизация сохраняют силу, навык сам не разрешает внешних действий.
