# Копирайтинг Романа Бермана

Методички, авторский голос и агентный процесс для написания, редактуры и аудита текстов.

Цикл ведёт текст от задачи через проверку фактов и читательский проход к принятой версии, сохраняя замечания и решения между запусками.

## Начало работы

Открой [мастер-промпт](prompt-copywriter.md) и дай задачу вместе с материалами.

Он выбирает режим, нужные методички и профиль [процесса](workflow.md).

Примеры запросов:

- «Отредактируй письмо, сохрани все факты и смысл, исправь только тяжёлые формулировки».
- «Проверь статью, покажи проблемы, исходник не меняй».
- «Подготовь полную заметку по этим материалам, после редактуры передай отдельному Ваське-читателю».
- «Подготовь сценарий в регистре Motion, после фактчека проведи отдельного Гусара и Ваську-зрителя».

## Работа в агентной среде

Точка входа навыка — [.agents/skills/copywriting-loop/SKILL.md](.agents/skills/copywriting-loop/SKILL.md).

Используй её из полного клона: относительные ссылки ведут к файлам репозитория, одна скопированная папка навыка без библиотеки недостаточна.

Роли описаны обычным Markdown и не привязаны к конкретной модели или провайдеру.

Среда запуска должна уметь передавать Ваське отдельный контекст; если этого нет, обязательный независимый проход остаётся невыполненным.

В обычном чате можно использовать методички и самопроверку, честно указав эту границу.

## Локальный инструмент

[scripts/loop.py](scripts/loop.py) на Python 3.9+ сохраняет версии текста и проверяет, относятся ли вердикты к актуальному SHA-256.

Он не вызывает модели и не выполняет содержательную проверку вместо рецензентов.

После подготовки первого черновика:

```sh
python3 scripts/loop.py init runs/article --source /path/to/draft.md --profile written
python3 scripts/loop.py status runs/article
```

Папка задачи должна быть новой, рабочие материалы в `runs/` исключены из Git.

Команды проверки, исправления, сборки читательского пакета и восстановления описаны в [руководстве](docs/loop-tool.md).

```sh
python3 -m unittest discover -s tests -v
git diff --check
```

## Границы

Проектные правила и поздние применимые решения автора сохраняют приоритет.

Готовый сценарий не означает готового видео, а готовый текст не означает разрешения на публикацию.

Обновление правил сверено с авторскими правками ноября 2026 и действующим процессом Motion; область переноса и проверка описаны в [заметках об обновлении](docs/migration.md).
